# TURIST bezgranits

Учебный сайт туристического агентства. Проект КР3 выполнен на основе КР1.

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Практическое занятие №12: адаптивная вёрстка, изображения, формы и таблицы.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог туров;
- `product.html` — страница тура;
- `order.html` — форма заявки;
- `contacts.html` — контакты;
- `css/style.css` — основные стили;
- `css/responsive.css` — адаптивные стили;
- `js/main.js` — обработка форм и модального окна;
- `images/` — изображения;
- `README.md` — описание проекта;
- `.gitignore` — исключения Git.

## Используемые технологии

HTML, CSS, JavaScript, Flexbox, CSS Grid, Git, GitHub. Bootstrap не используется.

## Реализованные изменения

- Mobile First и медиазапросы;
- адаптивные навигация, баннер и сетки карточек;
- перестроение каталога и бокового фильтра;
- адаптивная страница тура;
- изображения с `picture`, `srcset` и `sizes`;
- форма заявки в одну или две колонки;
- горизонтальная прокрутка таблицы внутри контейнера;
- адаптация карты и контактной информации.

## Проверка

Проверены пять страниц на ширинах 360, 430, 768, 1024 и 1440 px. Проверены формы, навигация и модальное окно. Горизонтальное переполнение страниц не обнаружено.
